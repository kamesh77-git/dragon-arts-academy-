# Dragon Ryu Arts Academy

Next.js (App Router) website for Dragon Ryu Arts Academy, Mannivakkam.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

- `app/` – layout, global styles, home page
- `components/` – page sections (interactive ones are client components)
- `lib/data.js` – courses, faculty, gallery and contact data
- `public/images/` – logo and gallery photos
